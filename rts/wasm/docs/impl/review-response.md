# Wasm implementation review response

This is the response to [review-feedback.md](review-feedback.md). The review
file is retained unchanged. Measurements live only in
[benchmarking_results.md](benchmarking_results.md), which is generated by
`test/native_api_parity/run_benchmarks.py`.

## Closed review items

- The environment matrix is derived from Lua registrations and model
  mutability. Generator assertions reject unsafe unsynced/UI exports, empty
  interfaces, and unimported interfaces.
- The signature gate compares the model with parsed WIT, generated native
  Rust, and Lua-derived signatures.
- The host adapter is split by module and built in both engine consumers.
- Redundant generated JSON is ignored; generated artifacts are marked in
  `.gitattributes`.
- Probe generation is part of the reproducibility check. Missing fixtures and
  default/error-only observations cannot silently count as parity.
- LuaUI visibility, degraded visibility fields, position variants, and
  radar-only no-value behavior have focused coverage.
- Callin aggregation has explicit deny/allow semantics and environment tests.
- The synced-to-unsynced direct channel has an unattended fixture.
- Synced timing is opt-in, deterministic, and fail-closed when unavailable.
- The generated adapter unit test now uses the canonical WIT record names and
  passes.
